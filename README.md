# 🌤 Skywatcher — Live Weather App

A stunning real-time weather web app with dynamic theming, hourly charts, and 5-day forecasts.

## Features
- 📍 Auto-detects your location
- 🔍 Search any city worldwide
- 🌡️ Current weather with humidity, wind, visibility, pressure
- ⏱️ 24-hour hourly temperature chart
- 📅 5-day forecast
- 🌓 °C / °F toggle
- 🎨 Dynamic background theme based on weather condition + day/night

## Setup

1. Get a free API key from [OpenWeatherMap](https://openweathermap.org/api)
2. Open `app.js` and replace `YOUR_API_KEY_HERE` with your key:
   ```js
   const API_KEY = 'your_actual_key_here';
   ```
3. Open `index.html` in your browser — done!

## Tech Stack
- HTML5, Vanilla CSS, Vanilla JavaScript
- OpenWeatherMap API (free tier)
- Google Fonts — Outfit

## Default City
**Berhampur, Odisha, India** — shown when location access is denied.
